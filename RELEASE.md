## Version info
* Add CYW55310 connectivity device support.
* Add LBEE5WV2GF module support.
* Add S27KL0642 QSPI memory configuration.

* mtb-pdl-cat1 >= 3.20.0
* mtb-pdl-cat2 >= 2.20.0
* mtb-xmclib-cat3 >= 4.6.0
* mtb-pdl-cat5 >= 4.0.0
* mtb-dsl-pse8xxgo >= 1.3.0
* mtb-dsl-pse8xxgp >= 1.3.0
